POSUK PRACTICE — OPEN/CLOSE SWITCH

1. Extract all files into the SAME folder as:
   student.html
   teacher.html

2. Double-click:
   INSTALL_APP_LOCK.bat

3. The installer patches the CURRENT files and creates backups.

4. Commit/push the changed student.html and teacher.html to GitHub.

Teacher page:
  🟢 Student App OPEN
  🔴 Student App CLOSED

Student page when closed:
  🔒 Currently Closed
  This practice page is currently closed.

Firebase setting:
  posukPractice/settings/studentAppOpen

If the setting does not exist yet, the app defaults to OPEN.
