# Whiteboard launch requirements

From the principal, recorded Nov 14, 2026.

## Essential for launch

1. **Save whiteboards:** teachers prepare, save, and reopen whiteboards for future lessons.
2. **Images:** easily copy and paste pictures onto the whiteboard.
3. **Shapes:** add, move, resize, and change the color of shapes, lines, arrows.
4. **Share with students:** distribute a whiteboard to the whole class; each student works on their own copy.
5. **Templates:** create and save reusable templates (e.g. Amdat, Chumash word boxes).
6. **Organization:** save whiteboards in folders by subject (Chumash, Mishnayos, etc.).

Student work must be saved in the program (not on the computer), so it works across computers.

## Later (must not delay launch)

- Multiple slides per file.
- Group collaboration on one board.
- Editable Hebrew text that students can drag into word boxes.
- Teachers view each student's saved work.
- Interactive multi-page PDF worksheets.

## Round 2 feedback

From the principal, recorded Nov 24-25, 2026.

1. Pointer tool selected when a whiteboard opens
2. Right-click menu with cut, copy, paste
3. Copy and paste a single item, not the whole page
4. Bring to front / send to back
5. Crop images
6. Upload PDFs and pictures
7. Image borders you can customize
8. Text alignment: left, center, right
9. Change the color of some words in a text box
10. Mixed sizes, fonts, bold and colors in one text box
11. Tables: insert, then add or delete rows and columns
12. Share files with other teachers
13. Turn slides into a printable PDF
14. New Slides button to start a new whiteboard
15. Save automatically
