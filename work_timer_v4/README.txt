WORK TIMER - VERSION 2

Open index.html in a web browser.

Main features:
- Client name field for each timer session
- Start, Pause/Resume, and Stop
- Live elapsed time and earnings
- $50/hour default rate, editable in Settings
- Today, week, and month totals
- Add forgotten sessions manually
- Edit and delete sessions, including client name
- Nicely formatted PDF time report
- CSV export including client name
- JSON backup and restore
- Data saved automatically in your browser
- Dark mode
- Works on desktop and mobile

PDF EXPORT:
Click Export PDF. A print window opens with a formatted report. Choose "Save as PDF" as the printer/destination and save it.

Important:
Your records are stored only in the browser on the device where you use the app.
Use the Backup button periodically if the records are important.

To publish on GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html, styles.css, and app.js.
3. Open repository Settings > Pages.
4. Under "Build and deployment," choose "Deploy from a branch."
5. Select the main branch and /root folder, then Save.

Version 4 export format:
- Choose From and To dates
- Optionally filter by client
- Same-day sessions are combined
- Export shows only Client, Date, Hours, and Amount
- PDF summary shows only Total Hours and Total Due
