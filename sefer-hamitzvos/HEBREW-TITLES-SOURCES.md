# Hebrew mitzvah descriptions

All 248 positive and 365 negative commandments use the opening description in Rambam's Hebrew Sefer HaMitzvot, as published by Sefaria (Warsaw 1883). The text is bundled locally; displaying a title needs no network request or AI call. These are descriptions in the source's Hebrew wording, rather than invented numbered labels.
